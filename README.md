# Hayitron Club

זהו בסיס ראשוני לפרויקט מועדון היתרון, המבוסס על האפיון והפרוטוטייפ.

## איך להריץ

1. פתחו את התיקייה בפרויקט.
2. הריצו שרת מקומי, למשל:
   - `python -m http.server 8000`
3. פתחו בדפדפן:
   - `http://localhost:8000`

## מה כולל

- עמוד בית עם מסרים מרכזיים
- דף כרטיסים
- אינדקס הטבות עם חיפוש וסינון
- אינדקס חנויות
- דף קהילה עם הצבעה ופורום
- אזור אישי עם התחברות וטעינה
- טופס הצטרפות עסק
- FAQ וצור קשר
- עוזר AI בסיסי

## שלבים הבאים

- חיבור למסד נתונים
- הרשמה והתחברות אמיתית
- ניהול כרטיסים ויתרות via API
- הרחבת תכני הקהילה
- שליחת בקשות שותפות לשרת
